## 记录 1：bug ① —— 删掉一个 std::move

- 注入点：`push_back(T&&)` 里 `m_data[m_size] = std::move(target);` → `= target;`
- ★ 预测（先写后跑）：只有 `MyVector.PushBackRvalueUsesMove` 会红 → ✅ **命中**（29 绿 / 1 红）
- 现象：
    moves  = 0（期望 1）      ← 根因
    copies = 1（期望 0）      ← 根因（铁证：右值 push 做了 copy）
    copies = 2（期望 1）      ← 余波（计数在用例内累积）
    moves  = 0（期望 1）      ← 余波
- 读法：EXPECT 不中断 → 只有**第一条**失败是根因，后面是余波
- ★ 调试器证据：断点 + F11 → 调用栈 = `MoveTracked::operator=(const MoveTracked&)`（拷贝版）
- 根因：`std::move` = `static_cast<T&&>`；删掉后实参是左值 → 重载决议选拷贝版
- 修法：恢复 `std::move` → 30/30 全绿
- 收获：① int 上移动/拷贝不可区分 → 29 条用例全绿也发现不了这个 bug
        ② 只有装了"事件量探针"的用例能看见 → 用例集就是探针
- 待验证观察：`PushBackToEmpty` 跑了 8039 ms（其它 0 ms）→ ASan 首次分配 vs 调试器开销
